## How to Test

### 1. Basic Resume Generation (No AI)
1. Copy data from Test Case 1 above
2. Paste into form fields
3. Keep AI toggle **disabled**
4. Select format (PDF recommended)
5. Click "Generate Resume"
6. Verify download works

### 2. AI-Optimized Resume
1. Use same Test Case 1 data
2. **Enable AI Refinement** toggle
3. Copy Job Description 1 into textarea
4. Select PDF format
5. Click "Generate Resume (AI-Optimized)"
6. Wait for AI refinement (5-10 seconds)
7. Download and compare with non-AI version
8. **Check:** Bullets should be rewritten to emphasize React, Node.js, AWS, microservices

### 3. Different Job Match
1. Keep same resume data (Test Case 1)
2. Enable AI
3. Use Job Description 3 (Backend Python) instead
4. Generate resume
5. **Check:** Should emphasize Python, Flask, PostgreSQL, APIs

### 4. Data Scientist Test
1. Use Test Case 2 data
2. Enable AI with Job Description 2
3. Generate resume
4. **Check:** Should highlight ML frameworks, Python, production ML, cloud platforms

## Troubleshooting

**If AI refinement fails:**
- Check console logs (F12) for error messages
- Verify API key is correct in `.env.local`
- Try with shorter job description first
- Check network tab for API response

**If resume looks unchanged:**
- AI may determine resume already matches job well
- Try more specific job description with clear requirements
- Compare original vs refined data in browser console

**If generation is slow:**
- AI refinement takes 5-15 seconds (normal)
- DeepSeek model is processing your request
- Wait for "Generating Resume..." to appear before canceling
